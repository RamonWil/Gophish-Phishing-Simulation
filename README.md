# Phishing Attack Simulation with GoPhish

A controlled cybersecurity lab using **GoPhish** to simulate phishing campaigns, analyze user interaction patterns, and evaluate common social-engineering risks.

The project was designed to better understand how phishing attacks work from a defensive perspective and identify ways organizations can improve security awareness and reduce email-based threats.

## Project Overview

This project involved configuring and running simulated phishing campaigns in a controlled environment.

I created phishing email templates, configured test campaigns, monitored interaction data, and analyzed the results to identify behaviors that could increase the likelihood of a successful social-engineering attack.

The project included:

- Configuring **3 phishing email templates**
- Tracking **30 simulated test interactions**
- Monitoring campaign engagement
- Analyzing user responses
- Identifying common email-security weaknesses
- Documenting findings and mitigation recommendations

The simulation was performed in a controlled testing environment.

```text

    |
    +---- Email Template

    |
    v
Campaign Analytics
```

GoPhish was used to configure and manage the campaigns, while MailHog provided a safe environment for capturing and reviewing test emails without delivering them to real users.

## What I Worked On

### Campaign Configuration

Created controlled phishing campaigns using custom email templates designed to demonstrate common social-engineering techniques.

### Email Testing

Used MailHog to safely capture simulated phishing emails during development and testing.

### Interaction Analysis

Reviewed campaign metrics to understand how users interacted with simulated phishing content.

Tracked behaviors included:

- Email interaction
- Link engagement
- Landing-page interaction
- Simulated credential submission behavior

### Security Analysis

Analyzed the results to identify factors that could make phishing emails more convincing, including:

- Urgency-based messaging
- Domain and sender verification
- Suspicious links
- Social-engineering cues

### Mitigation Recommendations

Based on the simulation results, I documented several defensive recommendations, including:

- Recurring phishing-awareness training
- Improved recognition of suspicious email cues
- Encouraging users to verify senders and domains
- Clear procedures for reporting suspicious emails
- Multi-factor authentication
- Periodic security-awareness simulations

## Results

The project demonstrated how relatively small changes in email wording, presentation, and perceived urgency can influence user behavior.

By analyzing **30 controlled interactions across 3 phishing templates**, I was able to evaluate common phishing indicators and develop recommendations aimed at improving user awareness and organizational email-security practices.
